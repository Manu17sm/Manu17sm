Preguntas

FAQ

Preguntas frecuentes pensadas para completar la web de cara a una presentación.

¿Qué incluye el plan gratis?

Biblioteca de ejercicios, propuestas de series/repeticiones, seguimiento diario, generador básico y un escaneo corporal al mes.

¿Cuánto cuesta Premium?

15 € al mes. Es un precio fijo dentro de esta maqueta y desbloquea las funciones avanzadas.

¿Qué analiza el scanner de comidas?

La demo está planteada para identificar alimentos y mostrar una estimación de micronutrientes. En una aplicación real, debería indicarse claramente el margen de error y la necesidad de revisar los datos.

¿El escaneo corporal es médico?

No. KALTRIA lo presenta como una herramienta de seguimiento y tendencias, no como diagnóstico.

¿K-IA es una IA conectada a internet?

En esta versión académica, el chat funciona con respuestas predefinidas en JavaScript para demostrar la experiencia de uso. Para conectarlo a un modelo generativo real haría falta un backend y configurar una API de IA de forma segura.
